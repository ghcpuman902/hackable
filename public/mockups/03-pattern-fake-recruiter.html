How it works

  1. A friendly recruiter offers a well-paid remote role.
  2. They send a coding test as a repo and ask you to run it today.
  3. Running npm install or opening it in VS Code runs hidden code.
  4. It steals saved logins and wallets, then leaves a backdoor.

Signs

  • Pay looks too good and the process is very fast.
  • The test must run on your own machine, today.
  • The repo has install scripts or odd files in .vscode.

What to do

  • Run tests in a throwaway cloud box or container, never your laptop.
  • Read package.json scripts before you install.
  • Check the recruiter on the company's own careers page.
